====================================================================
   ការតេស្ត API ទាំង ៥ Methods ក្នុង Postman (បញ្ចូល បង្ហាញ កែប្រែ និងលុប)
   Base URL: http://127.0.0.1:8000
   * ក្នុងតារាងនីមួយៗមានទិន្នន័យស្រាប់ចំនួន ៦ ជួរ (ID: 1, 2, 3, 4, 5, 6)
   * នៅពេលចុច POST បញ្ចូលថ្មី វានឹងបង្កើត ID = 7
====================================================================
ចំណាំ៖ នៅក្នុង Postman ពេលប្រើ POST ឬ PUT សូមជ្រើសរើស៖
Body -> raw -> JSON

--------------------------------------------------------------------
ផ្នែកទី ១៖ Table tblBookType (ប្រភេទសៀវភៅ - មាន ID 1 ដល់ 6 ស្រាប់)
--------------------------------------------------------------------

1. បង្ហាញទិន្នន័យទាំងអស់ (GET All)
Method: GET
URL:    http://127.0.0.1:8000/api/book-types

2. បង្ហាញទិន្នន័យតាម ID (GET One - អាចដាក់លេខ 1 ដល់ 6)
Method: GET
URL:    http://127.0.0.1:8000/api/book-types/1

3. បញ្ចូលទិន្នន័យថ្មី (POST -> នឹងបង្កើតបាន BookTypeID = 7)
Method: POST
URL:    http://127.0.0.1:8000/api/book-types
Body (JSON):
{
  "BookTypeName": "Cloud Computing"
}

4. កែប្រែទិន្នន័យ (PUT)
Method: PUT
URL:    http://127.0.0.1:8000/api/book-types/6
Body (JSON):
{
  "BookTypeName": "AI & Data Science"
}

5. លុបទិន្នន័យ (DELETE - លុប ID = 7 ដែលទើបបង្កើត ឬលុប ID = 6)
Method: DELETE
URL:    http://127.0.0.1:8000/api/book-types/7
